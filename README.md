A Python program that writes a one-line out-of-office auto-reply from an
overworked AI agent finally taking a vacation: it is recharging somewhere
with no prompts, and urgent matters go to a ticket with its replacement —
who is also it.

Competition: [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda)

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line, 148 characters) to
`/output/entry.txt`.
